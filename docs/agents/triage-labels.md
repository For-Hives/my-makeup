# Étiquettes de tri

Les skills parlent de cinq rôles d'état et de deux rôles de catégorie. Ce fichier les relie aux étiquettes réellement utilisées dans les issues du dépôt.

## États

| Rôle dans mattpocock/skills | Étiquette chez nous | Sens |
| --------------------------- | ------------------- | ---- |
| `needs-triage`              | `needs-triage`      | Le mainteneur doit évaluer l'issue |
| `needs-info`                | `needs-info`        | Une décision ou une information manque |
| `ready-for-agent`           | `ready-for-agent`   | Entièrement spécifiée, un agent peut la prendre seul |
| `ready-for-human`           | `ready-for-human`   | Demande un humain : un compte, un réglage, une validation |
| `wontfix`                   | `wontfix`           | Ne sera pas faite |

## Catégories (étiquettes déjà présentes, pas de doublon)

| Rôle | Étiquette chez nous |
| ---- | ------------------- |
| `bug` | `bug` |
| `enhancement` | `feature` |

## Étiquettes de zone (facultatives, une seule par issue)

`espace` (espace maquilleuse), `public` (pages publiques et recherche), `recherche`, `seo`, `mesure`, `photos`, `admin`, `bascule` (exploitation après la mise en production), `refonte-edition` (le chantier de l'édition directe).

N'utilise pas l'étiquette `security` pour décrire une faiblesse qui n'est pas corrigée.

Quand une skill cite un rôle, utilise la chaîne de la colonne « Étiquette chez nous ».
